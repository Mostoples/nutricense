# Foto untuk halaman company profile

Simpan berkas dengan nama persis seperti di bawah ini, lalu deploy ulang.
Selama berkas belum ada, halaman tetap tampil rapi: foto grup diganti kotak
petunjuk, dan foto anggota diganti inisial nama.

| Berkas             | Dipakai di                    | Saran ukuran         |
|--------------------|-------------------------------|----------------------|
| `team-group.jpg`   | Foto bersama pada seksi Tim   | 1600×1000, lanskap   |
| `team-1.jpg` … `team-6.jpg` | Kartu anggota tim    | 800×1066, potret 3:4 |

Nama dan peran tiap anggota disunting di `js/site.js`, pada array `TEAM`
di bagian atas berkas.
